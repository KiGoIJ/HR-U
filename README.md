# АСУЛС · Заявки

Кадровый контур: должности, подача заявок, рассмотрение, пользователи.

## Вход

| ФИО | Пароль | Роль |
|-----|--------|------|
| Администратор | admin | всё + мастер-пароль |
| Кадровик | kadry | рассмотрение + мастер-пароль |

Мастер-пароль `123456` — только admin/reviewer.  
Кандидаты: ФИО + пароль, без мастера.
