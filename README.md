# АСУЛС · Модуль обзвонов

Интерфейс в стиле [АСУЛС УФСБ](https://kigoij.github.io/ACULS/) (slate + matte gold):

- экран входа + мастер-пароль
- шапка, карточки, статистика, протокол
- Firebase Realtime Database
- обзвоны в **Discord** (без реальных номеров)

## Модули

| Вкладка | Кто | Что |
|---------|-----|-----|
| Обзор | все | сводка, очередь, последние итоги |
| Вакансии | все | открытые должности |
| Заявка | все | регистрация кандидата (RP + Discord) |
| Обзвон | host/admin | очередь, скрипт, вопросы, результат |
| Результаты | все | публичное табло |
| Начальство | admin | поставить / снять вакансии |
| Протокол | все | журнал IN/OUT + сырые данные |

## Вход по умолчанию

| ФИО | Пароль | Роль |
|-----|--------|------|
| Администратор | `admin` | начальство |
| Ведущий | `host` | обзвон |

**Мастер-пароль:** `123456` (как в АСУЛС, 6 цифр)

## Firebase

Данные модуля в ветке **`calldesk/`** (не пересекается с `employees` основного АСУЛС).

В Rules добавьте доступ к `calldesk` (см. `database.rules.json`).

## GitHub Pages

Залить файлы **в корень** репозитория:

```
index.html
style.css
app.js
database.rules.json
.nojekyll
README.md
```

Pages → `main` → `/ (root)`.

Можно отдельный репо (например `HR-U` или `ACULS-CALLS`) либо подпапку — тогда поправьте пути.
