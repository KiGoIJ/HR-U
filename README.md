# АСУЛС · Заявки на должности

Страница подачи и рассмотрения заявок (не форум).

## Вход

| ФИО | Пароль | Роль |
|-----|--------|------|
| Администратор | admin | должности + рассмотрение |
| Кадровик | kadry | рассмотрение |

Мастер-пароль `123456` — **только** при входе Кадровика / Администратора.  
Кандидаты входят по ФИО + пароль, без мастер-пароля.

## Разделы

- **Должности** — список открытых вакансий (создаёт админ), подача заявки
- **Мои заявки** — статусы
- **Рассмотрение** — кадровик/админ
- **Должности (админ)** — открыть/закрыть/создать
- **Пользователи (админ)** — создать/изменить/удалить, роли

Демо-должности не создаются. Данные Firebase: `apps/`
